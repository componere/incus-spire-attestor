# Security Policy

There is no supported release line yet, and this repository does not define a support window.

## Reporting a vulnerability

Report vulnerabilities privately at <https://github.com/componere/incus-spire-attestor/security/advisories/new>.

Do not use public GitHub issues, pull requests, discussions, or other public channels for vulnerability reports. Use public issues only for non-sensitive bugs.

When you report a vulnerability, include as much of the following as you can:

- security impact
- steps to reproduce or a minimal proof of concept
- affected version, commit, or deployment identifier

## Response process

Maintainers review private reports and may follow up through the advisory for clarification, a fix, or coordinated disclosure. This policy does not promise an acknowledgement or fix timeline.
